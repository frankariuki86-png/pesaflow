# PesaFlow MVP Roadmap

## Phase 1: Foundation

- Supabase project
- Auth setup
- Profiles and roles
- Database and RLS
- Web onboarding

## Phase 2: Personal finance

- Transaction import
- Categories
- Budgets
- Savings goals
- Dashboard summary

## Phase 3: Business

- Business creation
- Sales and expense records
- Product stock
- Profit calculations
- Daily close summary

## Phase 4: Chama

- Chama creation
- Members and invites
- Contributions and loans
- Reports and statements

## Phase 5: Monetization and release

- Premium gating
- Daraja integration
- Payment verification
- Admin reporting
- Security testing

## Delivery rule

Do not build full business and chama features before the personal finance flow is working and secure.

The first public MVP should be a clean personal-finance-first product with business and chama scaffolding behind it.
